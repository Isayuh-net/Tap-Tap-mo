Import students

Add a whole class or the whole school from a spreadsheet. Cards are assigned afterwards.

1. Prepare the file

  • Use the school's enrollment list (for example the SF1 School Register), or fill in the blank template.
  • It needs columns for the student's name, Grade, Strand and Section. Recommended: LRN, parent or guardian name, and parent mobile number.
  • The name can be one column ("Dela Cruz, Juan, Santos") or separate First, Middle and Last Name columns.
  • In Excel, choose File > Save As > CSV UTF-8. Format the LRN column as Text first, or Excel may change long numbers.

2. Choose the CSV file
