Register student and card

Used during enrollment. Plug a USB RFID reader into this computer.

Click here first if the number doesn't appear.

What happens next

  1. The card is linked to the student when you click Save and send verification code.
  2. A 6-digit code is texted to the parent's mobile number.
  3. The parent shows or reads the code to you, and you enter it.
  4. Only verified numbers receive attendance texts.
  5. If the parent isn't here, save anyway. Tap the same card later to finish verifying.
